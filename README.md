# Aprendendo SASS

Projeto simples criado para estudar e praticar o pré-processador SASS (Syntactically Awesome Stylesheets), focando em:

- Organização modular de arquivos
- Uso de variáveis e mixins
- Separação de estilos por responsabilidade (base, layout, componentes)

## 🚀 Tecnologias

- HTML5
- CSS3
- SASS

## 📂 Estrutura

- `_variaveis.scss` – cores, espaçamentos e fontes
- `_base.scss` – estilos globais
- `_layout.scss` – estrutura e containers
- `_componentes.scss` – botões, textos, interações

## ▶️ Como usar

Clone o projeto, edite os arquivos `.scss` e use um compilador de SASS (como o VSCode + Live Sass Compiler) para gerar o `style.css`.
